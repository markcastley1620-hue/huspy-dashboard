
## Daily Run Pipeline Change
- Market scrape no longer runs daily — now every other day (even-numbered days)
- Only scrapes market data for communities with NEW listings (compared to previous snapshot)
- Huspy listing scrape still runs daily
- On non-market days, Supabase enrichment uses the most recent market data file
- Massively reduces ScrapingBee credit burn (~140 calls → only new-listing communities × 2)
- Updated daily_run.py and cron job payload
